# ARNIX IPTV PLUS

Лёгкий набор инструментов для M3U-плейлиста и проверки сетевых прокси.

## Важно о геоблокировке
Проект **не обходит географические, подписочные или иные ограничения источников**. Публичные прокси неизвестного происхождения не включены: они могут перехватывать трафик, подменять ответы и собирать данные. Используйте только прокси, которыми вы управляете или которые вам разрешил использовать поставщик контента.

## Состав
- `playlist.m3u` — стартовый плейлист с Первым каналом.
- `channels.json` — редактируемый список каналов.
- `proxy_check.py` — проверяет доступность указанных вами HTTP(S)/SOCKS-прокси через HTTPS-тестовый адрес.
- `build_playlist.py` — создаёт M3U из `channels.json`.

## Запуск
```bash
python -m pip install -r requirements.txt
python build_playlist.py
```

Проверка собственных/разрешённых прокси (по одному URL на строку в `proxies.txt`):
```bash
python proxy_check.py proxies.txt
```

Поддерживаются HTTP(S), SOCKS5 и SOCKS5h. Для SOCKS установите зависимости из requirements.txt.

## Ограничения
Проверка прокси подтверждает только сетевую доступность тестового HTTPS-сайта. Она не подтверждает доступность телеканала и не снимает геоблокировку. Для просмотра используйте официальный источник, доступный в вашем регионе, и соблюдайте условия поставщика.
